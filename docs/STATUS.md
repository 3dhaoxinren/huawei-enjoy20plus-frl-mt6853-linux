# 状态：2026-11-02

## 历史真机确认

- 原生 Linux 服务环境和本地 GPU 监控界面曾运行。
- 用户确认显示、触摸、页面切换、Wi-Fi 快捷入口、熄屏和电源键唤醒正常。
- Wi-Fi 缓存列表优化后用户确认进入更快。
- 亮度滑条使用 6600 原始满量程，支持连续百分比；用户确认跟手且比旧上限更亮。
- 静态画面按需更新，GPU 休眠与 0% 读数可为正常现象。

## 本机与公开附件范围

项目所有者确认，本机移植项目已有可在 Bootloader 解锁后直接刷写的版本。解锁是必要前提，未解锁不能直接刷入。此前混入的启动校验/显示接管故障来自其他项目改动，不列为本项目现存故障。

2026.11.02 系统镜像发布增加了当前系统净化重建的 4 GiB rootfs、配套标志、离线验证记录、第三方版权及源码材料，详见 [ROOTFS-20261102.md](ROOTFS-20261102.md)。本次公开整理没有重新对手机执行刷写或冷启动测试。

## 发布缺项

- 本次重建镜像在目标设备上的新增冷启动和全功能回归记录。
- 与设备清单完全匹配的全部底层运行时源码；例如已整理的服务器健康检查仍依赖未随此快照发布的 `vendor_boot.py`。
- 厂商 GPU/Bionic、APEX、触摸/电源等二进制依赖的合法取得和匹配流程。
- 原构建脚本仍有本地路径，尚未完成通用一键构建。
- `server/fuel/service.py` 是当前清单匹配的源码，但其 `fuel_runtime`、`state` 等依赖未在本快照补齐；单元测试使用明确的模拟模块。
- GPU renderer 本次未重新交叉编译，设备渲染测试未重跑。
- GUI 关机/重启、备份入口、长时历史、自动亮度及更多硬件功能不作为本次已完成项目。

## 镜像审查

历史两份 v15 serial-fd ramdisk 的 SHA256 与历史刷写记录一致，系统镜像 Release 继续复用相同附件。新 rootfs 在空白 ext4 中构建，经过文件级回读、权限/xattrs/硬链接检查、e2fsck 和 V15 几何/特性校验。

旧 `rootfs-v3-integrated.ext4.gz` 是后续面板和服务器更新之前的快照，没有把它原样公开。新镜像来自随后取得的 USB 文件级导出，已清理已知个人绑定，并新增每台设备独立生成身份的首次启动流程；启动文件变更已同步 payload 清单。测试范围见本次 Release 记录。
