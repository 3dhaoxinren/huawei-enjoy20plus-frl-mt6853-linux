# 首次公开发布范围

日期：2026-11-02（北京时间）。目标仅为华为畅享 20 Plus / FRL / MT6853，不包含 K20P。

## 阶段与验收

1. 从现有源码交付包按目录白名单整理代码；不复制整个工作目录、设备日志或私有配置。
2. 保留运行逻辑和固定校验值，修正测试在公开目录中的导入位置；区分旧功能测试和当前功能测试。
3. 运行离线单元测试，检查凭据模式、个人路径、文件类型和差异；生成公开文件 SHA256 清单。
4. Git 仓库发布代码及文档；镜像放 Releases，每个附件单独校验。
5. 完整 rootfs 必须另外完成净化重建、配套检查和真机启动验证，不将旧 rootfs 当作最新版。

这次没有给手机刷写、部署或重启。主机测试通过不代表已修复手机启动/显示问题。

## 回退

本次整理在独立副本完成，原始源码和镜像未改动。公开仓库可通过 Git revert 撤回提交；附件可撤下，但已被下载的文件无法收回，因此不发布密钥、设备身份/校准分区或使用中的整盘镜像。
